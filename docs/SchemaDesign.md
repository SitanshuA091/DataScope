| Table              | Main attributes                                                                                                                                                                                   | Purpose                                                                                        |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------- |
| `users`            | `id`, `google_sub` unique, `email`, `name`, `avatar_url`, `created_at`                                                                                                                                 | User created/found after Google OAuth callback.                                                |
| `workspaces`       | `id`, `user_id`, `title`, `created_at`, `updated_at`, `deleted_at`                                                                                                                                     | A user-owned saved analysis space.                                                             |
| `datasets`         | `id`, `workspace_id`, `name`, `current_version_id`, `created_at`                                                                                                                                       | Logical dataset within a workspace; lets revised uploads belong together.                      |
| `dataset_versions` | `id`, `dataset_id`, `version_number`, `original_filename`, `storage_key`, `checksum`, `file_size`, `row_count`, `column_count`, `schema_json`, `validation_status`, `validation_error`, `created_at`   | One uploaded CSV/Parquet version and its lightweight schema overview.                          |
| `conversations`    | `id`, `workspace_id`, `dataset_version_id`, `active_columns_json`, `created_at`, `updated_at`                                                                                                          | Stores the current dataset context and selected columns for a chat/exploration session.        |
| `messages`         | `id`, `conversation_id`, `role`, `content`, `analysis_run_id` nullable, `created_at`                                                                                                                   | Persistent user questions and assistant responses.                                             |
| `analysis_runs`    | `id`, `workspace_id`, `dataset_version_id`, `conversation_id`, `user_request`, `status`, `celery_task_id`, `cache_key`, `agent_plan_json`, `error_message`, `started_at`, `completed_at`, `created_at` | One investigation/job; persists `queued`, `running`, `completed`, `failed`, `cancelled` state. |
| `tool_executions`  | `id`, `analysis_run_id`, `tool_name`, `arguments_json`, `status`, `result_json`, `duration_ms`, `error_message`, `created_at`                                                                          | Records each selected EDA tool, its validated arguments, and computed output.                  |
| `artifacts`        | `id`, `analysis_run_id`, `tool_execution_id` nullable, `artifact_type`, `storage_key`, `mime_type`, `created_at`                                                                                       | References generated plots, downloadable tables, or exports in R2.                             |


- UUIDs for primary keys
- index everything
- Use JSONB for flexible things: schema_json, selected columns, agent plans, tool arguments, and structured EDA results.
- since `redis` will store cache results use `analysis_runs.cache_key` will give persisted equivalent result after expiration from redis
